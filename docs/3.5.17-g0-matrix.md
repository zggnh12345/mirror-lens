## 2. 跨 Registry 副本（B 层）与 G0 的关系

- 副本候选只处理 **Manifest 整段 200**：完整读入临时文件、校验 `Content-Length` 与正文
  Digest，然后整文件提交。它**不进入** Range/206、`.part`、resume、Midfill 路径，
  因此第 2/3/4/6/7 项对 B 层不适用；第 1/5/8 项由上述用例覆盖（B 层自身的
  Digest 与临时文件生命周期另有 `TestReplica*`）。
- 「Source 切换后 `plan.Upstream` 未同步」这一类问题在 B 层不成立：副本路径从不改写
  `plan.Upstream`，只把候选 URL 作为一次性下载目标；缓存键始终是权威 `plan.CacheKey`。
