### 2.1 缓存与 epoch

- 应用启动日志：`私有认证已开：[quay.io gcr.io]（Access Token 必需，缓存绕过生效）`
- `meta.registry_cache_epoch = 2`，普通重启不递增。
- `registry_host_gen` 最终：`quay.io=3`、`gcr.io=7`（多次删除/重建/改密后的真实代次）。
- `cache_entries` 最终为 1，只有公共 manifest；私有层 digest `282b620f…` 的缓存行数为 0。
- 私有 manifest 响应 `Docker-Content-Digest: sha256:af5b4d9d…`，公共 manifest 为 `sha256:ed03fd2f…`，两者内容不同，排除“同内容误判”。

### 2.2 真实 Bearer 细节

- 自建 Token 服务使用 RS256，JWT header 带 libtrust 兼容 `kid`；Registry `rootcertbundle` 校验通过。
- 真实请求链：应用先匿名请求 → 收到 `401` Challenge → 解析 `https://gcr.io/token` → 用 `robot` Basic 取 Token → 带 `Bearer` 重试 → `200`。
- Token 端点日志：
  - `token service=gcr.io scope=repository:private/alpine:pull auth=basic`
  - `token service=gcr.io scope=repository:private/alpine:pull auth=none`
- 20 次连续 manifest 只触发 1 次 Token 请求；500 次命中路径新增 0 次。
