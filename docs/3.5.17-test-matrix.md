## 4. 测试夹具与纪律

- SQLite 多连接并发（T58）：真实 sql.DB 多连接，断言 F08 约束与无 database is locked。
- 确定性取消竞态（T52–T54）：用 channel 屏障控制 Dispatched/取消时序，禁止随机 sleep。
- A/B 集成（T62）、故障注入（Hedge/Midfill/源失败）：用隔离测试 Registry，不伪报真实外网。
- 性能（B15）：5 组配对测试，报告中位数、P95、吞吐、CPU、内存、错误率、Digest 一致性；不认单次峰值。
- 反向核对：文档引用的每个测试名与实际 `go test ./... -list` 清单求差集，虚报必须清除。
- -race 偶发（TestPrivateAndPublicConcurrentDoNotShareCache）：单跑/重跑隔离后如实标注，不写成稳定缺陷，也不因一次通过宣称全绿。
