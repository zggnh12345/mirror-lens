## 2. 冻结公式

- G = N × max(W+1, C×A, 2) + 4，N=200（cfg.Limits.GlobalConcurrency）、W=4（默认，2~16）、C=2、A≤2、Preflight 独立池 4。默认 G=1004，W=16 时 G=3404。limits.enabled=false 时内部 Registry RequestScope 仍用 cfg.Limits.GlobalConcurrency 作为 N 硬上限，不得变无限大。
- R = 16（逻辑 Attempt 累计硬上限）。
- P = 8192（RequestScope 级应用层受控 RoundTrip 派发硬上限）。
- RangeWorkCap = 1024；分段计划上限 256；每 Range 分段最多 4 个目标（含官方源）；Preflight 上限 min(实际目标数, 2×Workers)。
- 256 × 4 = 1024，与 RangeWorkCap 精确一致。P=8192 为工程保护上限：1024 RangeWork + Preflight ≤32 + main/A/B/fb/Authority + 有界 Token/重定向，远低于 8192。
