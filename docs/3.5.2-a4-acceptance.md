## 3. A3 真实链路

`internal/runner/a3_e2e_test.go`，真实 `httptest` Registry + 真实
`probe.ProbeRegistryHost` + 真实 SQLite + 真实 `Once`（6 个场景）：

| 场景 | 断言 |
| --- | --- |
| 真实 HTTP 成功 | cap=1 写回，候选可见，退避计数为 0 |
| 跨 Host | A 成功不改 B 的代次/排期/失败计数；B 的 5xx 只影响 B |
| 陈旧快照 | 代次推进后不写结论、不写退避，`state`/`rec_failures` 不变 |
| 凭据变更 | 真实 `ApplyCredChanges` 在探测返回前执行：不写结论、不 Block、计数全 0 |
| hard-excluded | `ListDueHostProbes` 不产出、Probe 零调用、`next_probe_at` 保持 0 |
| 失败结论 | 不进入候选 |

SSRF 防护只在测试进程内通过 `probe.Configure(true)` 放开（httptest 跑在回环），
结束后恢复；生产默认不变。
