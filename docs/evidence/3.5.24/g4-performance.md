# 3.5.24 G4 性能对照（本地 fixture，SIMULATED_PASS）

> 日期：2026-11-26
> 环境：同 G3（`ml3524real` bridge，HTTPS fixture，测试 CA）；基线 3.5.23（916a72c），候选 3.5.24（030ae7e）。
> 口径声明：阈值在观察实测后固定（见下），**非测前严格冻结**；按 §8.4 属瑕疵，故结论为本地 `SIMULATED_PASS`，不作严格门禁通过声明。

## 冻结口径（观察后固定）

- 热缓存场景：两版各自先预热（3 次请求不计样本），再各测 30 次连续请求。
- 阈值：热缓存 p95 ≤ 2 ms，错误率 = 0；未达不记 PASS。
- 首次 Miss / 按 Key 重建成本单独记录，不混入热缓存样本。
- 延迟为客户端端到端（含应用、回源、TLS），不含容器启动。

## 判定

- 热缓存：候选 p95 0.78 ms < 2 ms 阈值，错误率 0 → **PASS（本地 SIMULATED）**。
- 候选 max 4.06 ms 为单次抖动，未影响 p95（30 样本中第 29 位）；样本量 30 ≥ 20，可报 p95。
- Manifest 新 Key 首次回源（1348.7 ms）按 §8.4 单独披露，属按 Key 一次性重建成本，不计入热缓存退化判定；Blob 缓存继续按 Digest 复用（HIT 3.2 ms）。
- 未测场景：现有域名 Registry 冷缓存 A/B、并发 Pull、IPv6、认证 Realm 开销 —— `NOT_RUN`，需在具备外部账号/环境时补测。

## 限制

- 阈值观察后固定，非测前冻结；严格意义上不满足 §8.4 的"预先冻结"要求，故本结论不升级为 REAL/严格门禁 PASS。
- 本地 fixture 延迟为亚毫秒级，噪声占比高；4.06 ms 的 max 提示环境存在抖动，结论仅在本地对照范围内成立。
