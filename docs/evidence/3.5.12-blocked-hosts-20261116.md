## 方法

- HTTP GET {base_url}/v2/{repo}/manifests/{tag} with Docker/OCI manifest Accept headers; redirects not followed
- On 401, parse WWW-Authenticate, request anonymous token, retry once with Bearer token
- probe.ProbeRegistryHost (product code) executed against each candidate Source; cap=-1 / incomplete_evidence
- Candidate Source precheck only; no Source was registered in production because every candidate base URL failed the /v2 precheck or required unavailable credentials
- 限制：These are HTTP-level candidate Source probes, not HostProbe task records. No HostProbe was scheduled because no candidate qualified as a Source.
