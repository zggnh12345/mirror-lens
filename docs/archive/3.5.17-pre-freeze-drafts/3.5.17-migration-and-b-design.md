### 1.2 部署期全局回退（已冻结原则）

| 项目 | 规则 |
|---|---|
| 新架构正常运行 | 所有请求统一进入新框架 |
| 旧 A 路径 | 迁移前基线 + 历史回归参考 |
| 运行期按请求回退 | 默认禁止 |
| 部署期全局回退 | 允许，整体切换版本/执行路径 |
| 单请求混合新旧 | 禁止（不得同时持两套 Claim/Lease/Attempt 计数） |
| 回退后预算 | 由回退版本自身完整执行其预算与准入，新旧不双重统计 |

理由：避免入口归属判定、两套 Claim/Lease/Attempt 生命周期、两套取消/释放路径、跨框架排障等长期复杂度。

## 2. B 实施设计

### 2.1 两种模式
- 默认顺序模式：权威站 AuthorityAttempt → 可信副本按固定顺序逐个访问（M=4）。
- 跨站竞速模式（显式选择）：首轮 C=2 竞速 → 身份投票校验 → 失败对未参与副本顺序补位 → 必要时 AuthorityAttempt。
- 无整个 B 总开关；B 模式与 A 的 Host star_race 独立，不互相隐式开启。

### 2.2 入口规则
- 无显式前缀：按既有解析确定权威 Registry（默认 docker.io）。
- 显式前缀：前缀 Registry 为权威站，但不自动授予其他 Registry 副本资格。
- 无 F08 可信映射：不做跨站发现，退回既有路由（2857）。

### 2.3 候选发现与排序
- 候选 = F08 可信映射（Host×Repo 信任）∩ 调度选中 ∩ A 星标资格 ∩ 跨站参选勾选（AUD-04 待裁定）∩ `source_host_caps` 能力/健康/熔断/安全。
- F01–F03：最近 50 样本窗口、`Score=0.6×SuccessRate+0.4×LatencyScore`（仅可测 TTFB 参与，无则 LatencyScore=0）、并列记账；动态排序只调 M 内顺序，确定性截断 M=4，请求开始时固定不运行中扩容。
- 跨站参选勾选语义（旧章 2736-2737/2810/2838）属 AUD-04，未经正式吸收不落 Schema/UI。

### 2.4 权威站（乙案）
- 独立于 M/C/补位；每逻辑请求每权威 Manifest Identity 最多一次 AuthorityAttempt。
- B.3 软比对与最终兜底共用该次 Attempt 及结果，不重复 Dispatched。
- 与 B/fb 共享 RequestScope 与 Identity Claim；`R_authority=1`。

### 2.5 fb
- 仅 Docker Hub 默认 registry-1.docker.io、非 library/xxx、未被 rememberedHost 改写时挂载（阶段2证据）。
- 最多 2 加速源 + 1 官方目标；每目标最多 1 Attempt；严格顺序；不叠加 Hedge；独立于 star_race。
- 不扩展为通用 fb（F18/F19 方向，用户裁定）。

### 2.6 保持的边界规则
- 只 Manifest 跨站竞速，不跨站竞速 Blob。
- 不按同名 Repository/404 猜测可信关系。
- 不把 Source Scheduler 扩展为跨 Registry Scheduler，不复制 Source 评分。
- 不破坏私有认证隔离（认证前绕过共享缓存、OfficialOnly 贯穿）。
- 不把 rememberHost/Docker→GHCR 特殊 fallback 通用化。

## 3. B16 重试（已冻结语义，保持）

- 粒度：per-Registry；所有顺序执行路径（默认顺序 + 竞速失败后补位）。
- 每顺序 Registry 首轮最多 A 个 Source Attempt；无有效胜者且存在可重试网络故障时，额外发出**一个串行** Attempt。
- 只对网络类失败重试（超时/连接失败/无回应）；不重试 404/401/403/429/5xx/无效 Manifest（明确响应类直接回退下一站）。
- 首轮跨站竞速参与的 Registry 不重试（不创建/消费 RetryToken）。
- 重试目标按本站固定候选顺序，不按竞速完成先后。
- 重试持有原 Claim；不清空 tried；不创建新 RequestScope；不绕过 R/G。
- Authority 不参与 M 的副本顺序重试。

## 4. Hedge / Midfill 接入（P0 联动）

- Hedge：响应头阶段真实请求（gateway.go:1080-1168）；第二路作为独立 Attempt 注册、CommitR、申请 G；未胜出取消不返还 R；Body 关闭；不得建第二套预算。
- Midfill：Body 阶段 Range 请求（rangeReq→cli.Do）；首段/分片各独立 Attempt 计入 R；探活独立配额进 G；Source Lease 与 G Lease 层级协调，禁止双重计数；主链取消后 taskCtx 立即退出（已实现机制，接入统一取消传播）。
