## 2. 配置说明（§9-2）

自定义 Registry Endpoint 由四个逻辑字段构成，映射为 `Source.BaseURL`：

- **scheme**：`https`（默认）或 `http`（需管理员显式选择并确认明文风险）。
- **连接地址（connect_host / url）**：域名或显式登记的公网 IP；未知域名无归属时返回 400，不再静默默认 docker.io。
- **端口（port）**：留空按 scheme 推导默认端口（443/80）；显式端口拼入 base_url。
- **归属 Registry（repo_host / host）**：`docker.io`、`ghcr.io` 等；已知 Hub 域名（含裸 `docker.io`）无 host 时自动归属，未知域名必须显式传 host。
- 旧配置兼容：既有 `url` 字段继续接受；显式 `host`/`repo_host` 优先。无新增用户可见配置项。
- 输入示例：`{"connect_host":"mirror.example.org","scheme":"http","port":"5000","repo_host":"docker.io"}` → `http://mirror.example.org:5000`。

## 3. HTTP 明文风险（§9-3）

- HTTP 为管理员显式选择：UI 增加明文警告并要求 `confirm()`；详情区对 HTTP 源显示「⚠ 明文 HTTP」标记。
- 风险：凭据与拉取内容明文传输，存在中间人/凭据暴露风险；不自动降级、不隐式放开。
- `internal/probe` 对显式 HTTP 源不再尝试证书探测，TLSOK 诊断标注“不适用（明文）”，不误报为“证书 OK”（大小写 HTTP 均识别）。
- 安全边界不因 HTTP 选择而放宽：F1/F2/F3 的回环/私网/Origin 隔离独立生效。
