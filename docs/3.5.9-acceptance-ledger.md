## 公共第三方 Source 实测

详细矩阵与 Blob/Digest 结果见 `docs/3.5.9-public-source-matrix.md`。

覆盖结论：

- 6/8 Host 有公共源：gcr.io、registry.k8s.io、quay.io、mcr.microsoft.com、registry.gitlab.com、public.ecr.aws。
- us-docker.pkg.dev、cgr.dev 未找到可用公共源，保持未覆盖。
- 公共源使用自己的 Realm；m.daocloud.io、gcr.mirrors.wusiyu.me 作为 Source 探活时均因 Realm 白名单失败。
- 公共 Source `gcr.procoding.cn` 已完成实际二进制探活、候选、Blob、Digest 和缓存实测；公共 Source 回退仍未完成。
