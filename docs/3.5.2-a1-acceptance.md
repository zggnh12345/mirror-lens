## 4. 冻结约束（A1 范围内不得改动）

- 恢复状态是 source 级，不是 Host 级。
- 候选三入口使用同一套 Guard 过滤机制（`SourceCandidates` / `Scheduler.CandidatesN` / Gateway 三路径），不逐项检查。
- `Filter` 返回独立结果、不修改输入；epoch 变化整体重试；三次耗尽返回空集并计数，不退化为未过滤列表。
- Guard token 绑定 gen + seq；`UnblockIfMatch` 双重匹配；`Block` 的 seq 分配在锁内。
- 单 Runner 是当前唯一支持的运行模型；同一 key 不允许并发 HostProbe；多 Runner / 多实例不受现有 Guard 与 claim 支持。
- TTL 秒级语义，配置最小 1s；成功时间恰好等于 TTL 边界仍有效。
- C6 只推进 `ok → expired`，CAS 含 `state` / `last_success_at` / `gen`；单事务 `BEGIN IMMEDIATE`。
- C6-E 不读 `source_health_scope`、不改 `source_health`、不改 `DeriveState` / `CommitHostProbe`、不新增状态、不修改 `ListDueHostProbes`。

2. **3.5.0 之前的非 Hub 源 `repo_host` 为空**：建列默认值 `''` 且无回填迁移，这类源被当作 Docker Hub，既不进种子集合也不进探测队列。既有数据兼容问题，C6-E 未引入也未解决。
